# 내전.gg

내전을 즐기기 좋게 만드는 서비스. 경매로 팀을 짜고, 자동으로 매칭하고, 결과까지 한번에.

## 기술 스택

### Backend
- Java 17
- Spring Boot 3.x
- Spring Data JPA, Spring Security, Spring WebSocket (STOMP)
- PostgreSQL 15, Redis 7
- Flyway

### Frontend
- React 18 + TypeScript + Vite
- TanStack Query, Zustand
- Tailwind CSS, shadcn/ui

### Infrastructure
- AWS (예정)
